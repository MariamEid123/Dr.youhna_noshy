# مكتب الدكتور يوحنا نصحي — بوابة العملاء
تشغيل: `cd server && cp .env.example .env && npm i && npm run dev` ثم `cd client && npm i && npm run dev` (يلزم MongoDB).
أول تشغيل ينشئ مدير عام من ADMIN_EMAIL/ADMIN_PASSWORD في .env — غيّر كلمة المرور فورًا.
الملفات تُحفظ في server/private_uploads خارج أي مسار عام وتُقدَّم فقط بعد فحص الملكية.
